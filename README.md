# Cake Maker

A cozy, cartoon cake-decorating game. Pick a frosting and glaze, pipe icing, drag on toppings and number candles, write a banner message, choose a backdrop, then save a picture or send your cake to a friend.

Shared cakes live entirely in the link, so there's no account or server.

Cooked up by [Madison O'Connor](https://madisonfoconnor.com).
